# 輕鬆學習系統（EasyLearn）

這套工具結合《大腦喜歡這樣學》的認知科學原理（番茄鐘、記憶組塊比喻、專注與發散模式）與 5 階段學習框架（學 → 練 → 教 → 間隔複習 → 應用），協助學生與成人在每次 5–10 分鐘內完成單一核心觀念的吸收與回想，避免「從頭念到尾卻抓不到重點」的時間浪費。

換電腦接續進度請先看 [HANDOFF.md](HANDOFF.md) 最上方三行。

## 核心設計

1. **10 秒破冰與 5 分鐘專注保護罩**：開局先給 1 題直覺題啟動正向回饋，降低開始讀書的心理門檻。
2. **記憶組塊（Chunking）與生活比喻**：每關只講 1 個核心概念，搭配白話比喻與語音朗讀。
3. **三階梯練習（答錯不扣分）**：依序經過「看範例 → 半提示 → 獨立作答」。連續答錯兩次時自動展開比喻提示，引導大腦切換視角。
4. **以教代學（正確率達 80% 解鎖）**：由學習者糾正「呆萌學伴 小泡」的常見錯誤。預設免金鑰即可點選互動，亦可於設定頁填入 Gemini / OpenAI / 本機 Ollama 金鑰進行自由對話教學。
5. **多邊形能力雷達圖與三層式 Dashboard**：
   - **六角形能力值**：支援切換「大腦學習六力」與「學科領域六力」，過關後即時呈現能力面積擴張。
   - **三層弱點診斷**：由「大科目 → 出版社／單元紅黃綠燈 → 章節具體缺失」逐層檢視，並提供單鍵 3 分鐘專項補強。
   - **間隔複習追蹤表**：記錄當天、第 1、3、7、14 天回想狀態；僅在第 7 與第 14 天延遲測驗皆通過時，才標記為「已精通」。
6. **全階段教材匯入中心**：
   - **國小／國中（康軒、翰林、南一）與高中 108 課綱**：內建單元與章節骨架，可一鍵載入。
   - **大學／研究所／成人自學**：提供「講義／筆記貼上轉卡器」，貼上重點文字即可自動拆解為 5 階段闖關卡，並支援 CSV 與 JSON 匯出入。

## 開啟方式

不需要安裝額外套件，使用瀏覽器打開 `index.html` 即可運作。若要在手機或平板透過區網開啟，可在專案目錄啟動簡易網頁伺服器：

```bash
python3 -m http.server 8080
```

接著於瀏覽器開啟 `http://127.0.0.1:8080`。
